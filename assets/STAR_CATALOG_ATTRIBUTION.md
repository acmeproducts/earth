# Star catalogue attribution

The generated `src/star-catalog.json` file is derived from
[BSC5P-JSON-XYZ](https://github.com/frostoven/BSC5P-JSON-XYZ) catalog data,

[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The source data is based on the Bright Star Catalogue, 5th Revised Edition
(Hoffleit and Warren, 1991), distributed by NASA HEASARC. The generated file
retains only J2000 direction, apparent visual magnitude, and approximate RGB
color. It was generated from source revision
`36b238ffb1964c858b419130e67858ad9adbd24e` using
`scripts/build-star-catalog.mjs`.
